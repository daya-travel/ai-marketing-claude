# her.solotrip / DAYA - Design-Paket

Dieses Paket enthaelt alles, was ein anderer Agent (z.B. Claude) braucht, um im
richtigen Look weiterzubauen. Reihenfolge zum Lesen: DAYA-DESIGN.md -> daya-tokens.css -> logo/.

## Welches Logo wird in den Posts verwendet?
In allen @her.solotrip Posts steht oben links die **Handle-Marke**: eine duenne
Linien-Glyphe (Pfeil + zwei Schallwellen-Bogen, die DAYA-Glyphe) in Cream #F4ECDB,
Strichstaerke 1.5, daneben der Wortmarken-Text "her.solotrip" in Archivo Bold.
Es gibt kein separates her.solotrip-Bilddatei-Logo im Projekt - die Glyphe ist inline
als SVG in jedem Post. Deshalb liegt sie hier jetzt als echte Datei.

### logo/
- her-solotrip-glyph-cream.svg / -emerald.svg - nur die Glyphe (Icon)
- her-solotrip-glyph-cream-1024.png - Icon als PNG, transparent
- her-solotrip-lockup-cream-transparent.svg - Glyphe + Wortmarke, transparent
- her-solotrip-lockup-cream-on-emerald.svg / -emerald-on-cream.svg - mit Flaeche
- her-solotrip-lockup-cream-1600.png / -on-emerald-1600.png - PNG-Varianten

### daya-brand/
Die offizielle DAYA-Marke (Bogen + Pfeil + Schallwellen): App-Icon, horizontale
Lockups, Favicons, Social-Card. Nur fuer DAYA selbst, nicht fuer @her.solotrip-Posts.

## Farben (Kurzfassung)
- Emerald: #0e3b2c / tief #06251b / Ink #051f17
- Night: #0b1014 (Canvas), Silber #d4dae0 (Text + Icons, nie reines Weiss)
- Warm: Cream #F4ECDB, Marigold #EFB050
- Icons sind IMMER Silber. Gold nie in oder an einem Icon.

## Schriften
Archivo (Display), Cormorant Garamond (Serif/Zitate), Caveat (Handschrift-Akzent),
Inter (Body). Alle via Google Fonts.

## Harte Regeln
1. Fotos: ausschliesslich echte reisende Frauen, nie Maenner, nie Studio-Models.
2. Kein Foto zweimal verwenden.
3. Keine Gedankenstriche (-- oder Geviertstrich) in Bildtext oder Captions, nur Bindestrich.
4. Icons silber, Gold nur als Hintergrund-Atmosphaere oder Text-Akzent.
5. Max 5 Hashtags pro Post, getrennt nach Instagram und TikTok.

## Formate
Carousel 1080x1350, Story/TikTok 1080x1920, Highlight-Cover 1080x1080.
TikTok-Safe-Area: oben 320px, unten 700px, Seiten 170px frei halten, Text mittig.
